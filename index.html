Overview

This project showcases a trained Hierarchical Deep Deterministic Policy Gradient (H-DDPG) agent operating in the AntBulletEnv environment. The agent learns to coordinate complex locomotion behavior through a modular actor architecture. Below you can find the evaluation video and key metrics.

Training Details

  • Environment: AntBulletEnv-v0 (PyBullet)
  • Framework: TonicRL + PyBullet
  • Episodes: 2000
  • Exploration: Gaussian noise (decaying)
  • Agent structure: Modular Actor-Critic with shared Critic
